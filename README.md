# human_writer ✍️
**Универсальный модульный движок генерации естественных текстов и отзывов без слопа и галлюцинаций.**

---

## 🎯 Проблема, которую решает `human_writer`
При массовой генерации сотен и тысяч отзывов / карточек / описаний напрямую через LLM (OpenAI, Gemini, Claude, Llama):
1. **Галлюцинации усталости (LLM Slop):** Нейросеть неизбежно скатывается в паразитные штампы (*«Для нас важно...»*, *«Стоит отметить...»*, *«Порадовало, что...»*), страдательный залог и неестественный книжный стиль.
2. **Фактологические галлюцинации:** LLM приписывает объектам свойства, которых нет (например, «подземный паркинг» в доме без паркинга или «блютуз» в механическом чайнике).
3. **Медленно и дорого:** Сетевые запросы на 20 000+ объектов занимают часы и съедают миллионы токенов.

---

## 🚀 Архитектурные принципы `human_writer`

1. **Fact-Locking Matrix (Жесткая привязка к фактам)**  
   Движок принимает карточку объекта. Если параметр `false` (например, `parking: 0`), фразы об этом свойстве математически исключаются из генерации.
2. **Zero-Slop Quality Gate**  
   Каждый сгенерированный батч проходит строгую валидацию перед записью:
   - 0 стоп-слов и паразитных клише.
   - 0 соединительных и длинных тире (`—`, `–`).
   - 0 утечек названий объекта (эффект реального жителя/покупателя).
   - 100% уникальность первых слов в предложениях.
3. **Модульные отраслевые пресеты (`presets/`)**  
   Библиотеки реального разговорного языка живых людей, разбитые по отраслям.
4. **Мгновенная производительность**  
   Генерация 25 000 текстов занимает **менее 2 секунд** на CPU.

## 📂 Структура репозитория

```text
human_writer/
├── core/                       # Ядро движка
│   ├── engine.py               # Детерминированная комбинаторика и слоты
│   ├── validator.py            # Slop-Shield валидатор
│   └── fact_filter.py          # Динамические фильтры доступности фраз
│
├── presets/                    # Отраслевые библиотеки фраз
│   ├── real_estate/            # Новостройки и ЖК (окна, лифты, УК, стяжка)
│   ├── ecommerce/              # Товары (материалы, швы, упаковка, доставка)
│   ├── auto/                   # Автодилеры и сервис (двигатель, ТО, салон)
│   └── travel/                 # Отели и апартаменты (завтраки, уборка, вид)
│
├── exporters/                  # Экспорт данных
│   ├── sheets_exporter.py      # Google Sheets API v4
│   └── jsonl_exporter.py       # Локальные датасеты
│
└── configs/                    # Проектные конфиги
    └── real_estate_default.json
```

## 🛠️ Быстрый старт

```python
from core.engine import HumanWriterEngine
from presets.real_estate import REAL_ESTATE_PRESET

engine = HumanWriterEngine(preset=REAL_ESTATE_PRESET)

# Передаем факты конкретного объекта
facts = {"has_parking": False, "has_concierge": False}
reviews = engine.generate(facts=facts, seed=42)

for r in reviews:
    print(r)
```
